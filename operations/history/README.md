# Historical service definitions

These units record one-off campaign admissions and recovery chains. Their
calendar dates have passed and they are not part of the current installation
set. Keep them for operational provenance; do not copy or enable them as live
services.

Recurring and reusable units remain in the parent `operations/` directory.
All user-service paths use systemd's `%h` home-directory specifier so the same
reviewed checkout layout can be installed under a dedicated Unix account.
